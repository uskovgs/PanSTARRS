# Get the RA and Dec for an object using the MAST name resolver

Get the RA and Dec for an object using the MAST name resolver

## Usage

``` r
ps1_mast_resolve(name)
```

## Arguments

- name:

  Name of object

## Value

list of ra, decl

## Examples

``` r
if (FALSE) { # \dontrun{
ps1_mast_resolve('Acrux')
} # }
```
