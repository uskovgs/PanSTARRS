# Check ra, dec params

Check ra, dec params

## Usage

``` r
validate_radec(ra, dec, .length = NULL)
```

## Arguments

- ra:

  (degrees) Right Ascension

- dec:

  (degrees) Declination

- .length:

  length of coordinates. If \`NULL\` (default) then coordinates can be
  any size.

## Value

If the check is successful, the function returns nothing.
